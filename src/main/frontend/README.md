# Nexus — Frontend

Interface de gestão de usuários, permissões e produtos, desenvolvida com React, TypeScript, Vite e Axios.

```powershell
npm ci
npm run dev
```

Com o backend em execução na porta 8080, acesse http://localhost:5173. Utilize `npm run build` para compilar e `npm run lint` para verificar o código.

Consulte o [README principal](../../../README.md) para instalação, arquitetura, API e configuração de e-mail.
